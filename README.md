# 🎨 عالم الألوان مع جنان

تطبيق ويب تقدّمي (PWA) للتلوين، مصمَّم خصيصًا لطفلة بعمر **3 سنوات** — يُثبَّت على الهاتف كتطبيق حقيقي بأيقونته، ويعمل **بدون إنترنت** من أول فتح.

## ✨ المميزات

- **12 صفحة تلوين مدمجة** (كتاب جنان الأول): رسومات كبيرة بخطوط سميكة تناسب أصابع الصغار — قطة، سمكة، فراشة، زهرة، شمس، بيت، سيارة، بالونات، أرنب، آيس كريم، تفاحة، ونجمة الليل.
- **تلوين بلمسة واحدة**: أداة التعبئة 🪣 هي الأداة الافتراضية — المسي اللون ثم المسي الرسمة.
- أدوات مرحة: فرشاة 🖌️، **فرشاة قوس قزح 🌈**، **طوابع** ⭐❤️🌸، وممحاة 🧽 — بأحجام ثلاثة بسيطة (بدون شريط تمرير معقّد).
- **ألوان كبيرة بأسمائها**: عند لمس اللون يظهر اسمه وتنطقه الأصوات العربية (إن توفرت على الجهاز).
- **أصوات تشجيعية** مولّدة داخل التطبيق (بدون ملفات صوت) + **احتفال بالقصاصات** عند حفظ اللوحة.
- **حفظ تلقائي** لكل صفحة، و**معرض أعمالي 🖼️** لكل اللوحات الملوّنة.
- **حفظ ومشاركة اللوحة** كصورة PNG مع اسم الفنانة وشريط قوس قزح (تدعم مشاركة واتساب على الهواتف).
- **منطقة والدين محمية** (ضغط مطوّل 3 ثوانٍ): رفع كتب تلوين PDF إضافية، حذف الكتب، إيقاف الأصوات، ومسح التلوينات.
- **يعمل دون إنترنت بالكامل**: الخط العربي والأيقونات وقارئ PDF كلها مضمّنة محليًا — لا حاجة للشبكة إطلاقًا بعد التثبيت.
- أمان للأطفال: لا إعلانات، لا روابط خارجية، الأزرار الخطرة كلها خلف ضغط مطوّل، وكل البيانات تبقى داخل الجهاز.

## 📦 محتويات الحزمة

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا (واجهة + منطق) |
| `manifest.json` | بيانات التثبيت (الاسم، الأيقونة، الألوان) |
| `sw.js` | العمل دون اتصال (Service Worker) |
| `icon-192.png` / `icon-512.png` | أيقونات التطبيق |
| `fonts/` | خط Baloo Bhaijaan 2 (عربي + لاتيني) مستضاف محليًا |
| `vendor/` | مكتبة pdf.js مضمّنة محليًا (لرفع كتب التلوين PDF دون إنترنت) |

## 🚀 النشر السريع (دقيقتان — بدون APK)

1. افتحي موقع **app.netlify.com/drop** (مجاني).
2. اسحبي مجلد المشروع كاملًا وأفلتيه في الصفحة → ستحصلين على رابط للتطبيق.
3. افتحي الرابط من الهاتف في متصفح Chrome.
4. من قائمة ⋮ اختاري **«إضافة إلى الشاشة الرئيسية / تثبيت التطبيق»**.

✅ سيظهر التطبيق بأيقونته على شاشة الهاتف ويعمل كتطبيق مستقل وبدون إنترنت.

## 📱 إنشاء ملف APK (للنشر على Google Play)

1. أكملي خطوة النشر أعلاه واحصلي على رابط `https`.
2. افتحي موقع **pwabuilder.com** والصقي الرابط ثم اضغطي **Start**.
3. اختاري **Android** ثم **Generate Package** — سيُنشأ ملف APK / AAB جاهز.

## 🧪 التجربة محليًا

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

> ملاحظة: التخزين يستخدم IndexedDB داخل جهاز الطفل — الكتب والتلوينات لا تغادر الجهاز أبدًا.

## 🏛️ أساس فروع الموقع الجديدة (هوية البشري)

بجانب تطبيق التلوين، يحتوي المستودع على **نظام تصميم موحّد** مستخرج من صفحة
«نتيجة الشهادة الثانوية للولاية الشمالية 2026»، ليُبنى عليه كل فرع جديد بنفس
الهوية: نفس الألوان الكحلية والذهبية، نفس الترويسة والعناوين، نفس بطاقة النتيجة،
نفس الإهداء، ونفس عدّاد الزيارات.

| المجلد | الوظيفة |
|---|---|
| `shared/` | نظام التصميم: `theme.css` + `fonts.css` + `site.js` + الشعارات والخطوط |
| `template/` | قالب صفحة كامل وجاهز — انسخه لبدء أي فرع جديد |
| `DESIGN.md` | دليل التصميم: الألوان، الخطوط، ترتيب الصفحة، والأدوات الجاهزة |

```bash
cp -r template/ اسم-الفرع-الجديد/
```

التفاصيل كاملة في **[DESIGN.md](DESIGN.md)**.
