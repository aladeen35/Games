# حاسبة حملي 🤰✏️

دفتر عائلي كرتوني لمتابعة الحمل والصحة النسائية — بطابع ورقة الدفتر المسطرة، الأقلام الشمعية، والحدود المرسومة باليد.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | شجرة العائلة الكرتونية (أسماء قابلة للتعديل بالنقر) + ملصق حالة الحمل |
| `calculator.html` | حاسبة الحمل بطريقتين: آخر دورة شهرية (قاعدة نايجل) أو موعد الولادة المتوقع — تعرض الأسبوع والشهر والأيام + حاسبة التبويض |
| `weeks.html` | تطور الجنين أسبوعاً بأسبوع (40 أسبوعاً) بمقارنات الفواكه ونصيحة لكل أسبوع |
| `tools.html` | يوميات الأم، قائمة حقيبة المستشفى القابلة للتعليم، وعداد ركلات الجنين اليومي |
| `health.html` | مقالات متجددة تلقائياً كل 24 ساعة (RSS عبر rss2json مع تخزين مؤقت) + مقالات مختارة |
| `community.html` | مجتمع الأمهات بأقسام مراحل الحمل الست |

## الهوية البصرية

- خلفية ورقة دفتر مسطرة مع خط هامش أحمر (CSS خالص)
- حدود مرسومة باليد (Hand-drawn borders) وملصقات بشريط لاصق ودبابيس 📌
- ألوان شمعية: أصفر هادئ، وردي فاتح، أزرق سماوي، أخضر نعناعي
- الخط العربي المرفق Noto Kufi Arabic (محمّل محلياً من `fonts/`)

## المقالات المتجددة

- `js/articles.js` يجلب خلاصات RSS طبية عبر `api.rss2json.com` ويخزنها مؤقتاً في `localStorage` لمدة 24 ساعة
- لتفعيل NewsAPI.org: ضعي مفتاحك في الثابت `NEWSAPI_KEY` أعلى الملف
- عند تعذر الجلب تُعرض المقالات المختارة المحلية دون أي خطأ ظاهر

## تطبيق PWA 📲

الموقع تطبيق ويب تقدمي كامل قابل للتثبيت على الجوال وسطح المكتب:

- `manifest.webmanifest` — الاسم والأيقونات والألوان واتجاه RTL + اختصارات (الحاسبة، عداد الركلات، المتابعة الأسبوعية)
- `sw.js` — عامل خدمة يخزّن هيكل التطبيق كاملاً عند أول زيارة، فيعمل الموقع **دون إنترنت بالكامل** (استراتيجية cache-first مع تحديث بالخلفية)
- زر «📲 ثبتي التطبيق» يظهر في الترويسة تلقائياً عند دعم المتصفح للتثبيت
- أيقونات مولدة بهوية الدفتر في `icons/` (192 و512 وmaskable)

ملاحظة: يتطلب عامل الخدمة تقديم الموقع عبر HTTPS أو localhost.

## حفظ البيانات

كل بيانات المستخدمة (أسماء العائلة، تاريخ الحمل، اليوميات، الحقيبة، الركلات) تُحفظ محلياً في `localStorage` — لا خادم ولا حسابات.

## التشغيل

```bash
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000` — (فتح الملف مباشرة يعمل أيضاً، لكن جلب المقالات الخارجية يحتاج تشغيلاً عبر خادم).

## تنبيه

المحتوى الصحي والحاسبات لأغراض توعوية فقط ولا تغني عن استشارة الطبيب المختص.
