# حاسبة حملي 🤰

موقع عربي (RTL) لمتابعة الحمل والصحة النسائية، مستوحى من أسلوب موقع 7amal.com.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: تعريف بالمنصة، الخدمات، مراحل الحمل، وأحدث مواضيع المجتمع |
| `calculator.html` | حاسبة الحمل (قاعدة نايجل) + حاسبة التبويض ونافذة الخصوبة |
| `weeks.html` | متابعة تطور الجنين أسبوعاً بأسبوع (40 أسبوعاً) مع نصيحة لكل أسبوع |
| `community.html` | مجتمع الأمهات: أقسام مراحل الحمل الست ونماذج مواضيع |
| `health.html` | مقالات توعوية في الصحة النسائية |

## التقنيات

- HTML5 / CSS3 / JavaScript خالص — بدون أي إطار عمل أو خطوة بناء
- تصميم متجاوب بالكامل (جوال / لوحي / سطح مكتب)
- خط Tajawal من Google Fonts
- هوية بصرية: أبيض نظيف مع لمسات وردية وزرقاء 💙🩷

## التشغيل

افتحي `index.html` مباشرة في المتصفح، أو شغلي خادماً محلياً:

```bash
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000`

## تنبيه

المحتوى الصحي والحاسبات لأغراض توعوية فقط ولا تغني عن استشارة الطبيب المختص.
