## 📶 اللعب عبر البلوتوث

بلا إنترنت وبلا حسابات: جهاز واحد يفتح الغرفة كمضيف فيظهر للأجهزة القريبة، والباقون يختارونه من قائمة البحث.

- **تحدّي الجرس:** شاشة اللعبة تفتح «📶 أجراس بلوتوث»، وكل لاعب يفتح «📱 هاتفي جرس» ويختار جانبه — ضغطة هاتفه تقرع جرسه على الشاشة. يعمل والهاتف عمودي.
- **أنا منو:** هاتف الوصّافين يعرض البطاقة، وهاتف المخمّن لا يرى إلا الوقت والنقاط.
- **ولعت:** الحكم يختار «📶 أجهزة قريبة»، واللاعبون يدخلون بـ«انضم كلاعب ← بالبلوتوث» بلا رمز غرفة.

الجسر الأصلي في [`BluetoothLinkPlugin.java`](android/app/src/main/java/sd/abujanan/hub/BluetoothLinkPlugin.java) (بلوتوث كلاسيكي RFCOMM)، وواجهته الموحّدة لكل الألعاب في [`shared/abujanan.js`](shared/abujanan.js).

## 🗂️ البنية

```
index.html               الشاشة الرئيسية (قائمة الألعاب)
manifest.webmanifest     تعريف التطبيق  ·  sw.js  العمل دون إنترنت (مولَّد)
icons/                   الشعار وأيقونات التطبيق
shared/                  abujanan.js (بلوتوث + زر الرئيسية + زر الرجوع) والخطوط
games/<اللعبة>/          كل لعبة مستقلة بملفاتها
android/                 مشروع Capacitor لبناء APK/AAB (تطبيق sd.abujanan.hub)
scripts/                 build-www.sh · build-sw.js · check-java.sh
```

## 🚀 التشغيل والبناء

```bash
# تجربة محليًا
python3 -m http.server 8000        # ثم افتح http://localhost:8000

# بعد إضافة أو تعديل أي ملف: تحديث قائمة العمل دون إنترنت
node scripts/build-sw.js

# بناء APK / AAB (يحتاج Java 21 + Android SDK)
npm install
npm run apk      # android/app/build/outputs/apk/release/app-release.apk
npm run aab      # android/app/build/outputs/bundle/release/app-release.aab
```

أو ادفع إلى الفرع ودع **GitHub Actions** يبنيه: [`.github/workflows/build-android.yml`](.github/workflows/build-android.yml) يرفع APK و AAB جاهزين في **Artifacts**.

> اللعب بالبلوتوث يعمل في نسخة **APK** فقط. في المتصفح تعمل كل الألعاب عدا وضع البلوتوث (تظهر رسالة توضّح ذلك).

## 🖼️ صور بطاقات «أنا منو»

البطاقة بلا صورة تُعرض برمزها ولون خلفيتها ولافتة اسمها. لإضافة الصور:

- **من داخل اللعبة:** «🖼️ صور البطاقات» → اختيار عدة صور معًا (يطابقها التطبيق بأسماء الملفات) — تُحفظ داخل الجهاز.
- **أو في المستودع:** ضع الصور في [`games/anamenu/cards/`](games/anamenu/cards/) باسم الـ `slug` من [`cards.js`](games/anamenu/cards.js) مثل `doctor-m.png`، ثم شغّل `node scripts/build-sw.js`.
