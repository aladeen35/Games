# 👑 ألعاب أثير

<p align="center"><img src="logo.jpg" width="200" alt="أثير"></p>

تطبيق واحد يجمع **ثلاث ألعاب**، بتصميم وردي لطيف مستوحى من شعار أثير (التاج الذهبي، القلوب، الغيمة المبتسمة والأزهار).
يعمل **دون إنترنت**، بلا إعلانات ولا تتبّع، وتُحفظ النتائج داخل الجهاز فقط.

## 📱 التثبيت

- **أندرويد (APK):** [`dist/AtheerGames-1.0.apk`](dist/AtheerGames-1.0.apk). انقليه إلى الهاتف، ثم افتحيه واسمحي بالتثبيت من مصادر غير معروفة.
- **ويب (PWA):** افتحي `atheer/index.html` من أي استضافة ثابتة، ثم اختاري «إضافة إلى الشاشة الرئيسية».

```bash
python3 -m http.server 8000   # من جذر المستودع، ثم افتحي http://localhost:8000/atheer/
```

## 🎮 الألعاب

### ☁️ فارس السحاب: قفز عمودي لا نهائي
فارس صغير بخوذة وريشة وتاج يقفز تلقائيًا من غيمة إلى غيمة نحو **قلعة حالمة في السماء**.
- التوجيه: لمس يمين الشاشة أو يسارها، أو الأسهم ⬅️ ➡️، أو إمالة الهاتف.
- النتيجة هي **الارتفاع بالأمتار** قبل السقوط، ويُحفظ أعلى رقم.
- غيوم عادية، وغيوم مبتسمة متحركة، وغيوم منقّطة تختفي بعد قفزة واحدة، ونوابض للقفز العالي، ونجوم ذهبية مكافئة.
- تتدرّج السماء من صباح باستيلي إلى غروب وردي ثم ليل بنفسجي مرصّع بالنجوم، وتقترب القلعة كلما ارتفعتِ.

### 🌌 دمج الأجرام: 2048 الفضائية
شبكة 4×4: اسحبي لتحريك كل الأجرام في اتجاه واحد، وكل جرمين متطابقين يندمجان في جرم أكبر:

غبار نجمي (2) ← كويكب (4) ← مذنّب (8) ← قمر صغير (16) ← قمر (32) ← كوكب أحمر (64) ← كوكب أزرق (128) ← كوكب الحلقات (256) ← عملاق غازي (512) ← نجم (1024) ← **شمس متوهّجة (2048)** ← عملاق أزرق ← مجرّة

- خلفية سماء ليلية بنجوم متلألئة وشهب وسُدُم.
- تراجع عن الحركات، وحفظ تلقائي للعبة، ومتابعة اللعب بعد الوصول إلى الشمس.

### ✏️ إكس أو على السبورة
شبكة 3×3 مرسومة بالطباشير على سبورة الفصل، مع إطار خشبي وحامل طباشير وممحاة.
- **وضعان:** لاعبتان على الجهاز نفسه، أو لاعبة ضد **ذكاء اصطناعي لا يُقهر** (Minimax مع تقليم ألفا-بيتا). أفضل نتيجة ممكنة ضده هي التعادل.
- رسوم متحركة للطبشورة وهي تكتب، وغبار طباشير، وصوت صرير، وممحاة تمسح السبورة بين الجولات.
- اختيار من يبدأ (أنتِ أو الذكاء)، وعدّاد للنتائج.

## 🛠️ البناء

```bash
bash atheer/android/build-apk.sh   # ← atheer/android/build/AtheerGames.apk
```
يستخدم نفس أدوات بناء تطبيق جنان (`aapt2` · `javac` · `zipalign` · `apksigner` · `android.jar`) ومُجمِّع DEX من `android/tools/`.

| المسار | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا: القائمة والألعاب الثلاث والأصوات المولّدة |
| `logo.jpg` · `icon-*.png` | الشعار والأيقونات |
| `fonts/` | الخط العربي محليًا |
| `android/` | غلاف أندرويد وسكربت البناء |
| `dist/` | ملف APK الجاهز |
