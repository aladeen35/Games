"via ESC-50" = the 5-second excerpt published in the ESC-50 dataset (github.com/karolpiczak/ESC-50), whose LICENSE file records the original Freesound author and license of each clip; only clips whose original is CC0 were used.
"via MineClone2" = sound file shipped in MineClone2/VoxeLibre (github.com/MineClone2/MineClone2, `mods/ENTITIES/mobs_mc/sounds`), credits from its `LICENSE-media.md`.
