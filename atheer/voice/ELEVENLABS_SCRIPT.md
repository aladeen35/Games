# سكربت تسجيل أصوات الألعاب على ElevenLabs

هذا الملف يحوي **كل جملة تنطقها الألعاب** مقسّمة إلى مقاطع صغيرة قابلة لإعادة الاستخدام، مكتوبة بالتشكيل الكامل حتى يكون النطق صحيحًا.
بعد التسجيل سنستبدل نطق الجهاز (TTS) بهذه المقاطع.

- إجمالي المقاطع: **433** ( عربي: **380** — إنجليزي: **53** )
- عدد الدفعات: **13** (11 عربية + 2 إنجليزية). **الدفعة 1 مسجّلة مسبقًا** (ملفاتها `voice/batch1*`) — ابدئي من الدفعة 2.
- لكل دفعة ملفات جاهزة: `voice/batchN_v3.txt` و`voice/batchN_v2.txt` و`voice/batchN_table.txt` و`voice/batchN.json`.
- القائمة الكاملة (المصدر الرسمي): `atheer/voice/voice_lines.json` — كل مقطع له `id` ثابت يصبح اسم الملف: `voice/ar/<id>.mp3` أو `voice/en/<id>.mp3`.
- الألعاب التي **لا تنطق شيئًا** حاليًا: الكرات، الطباشير، الفضاء، القفز، الأنابيب.

## 1) توجيه الصوت

- **الصوت:** بنت صغيرة بعمر 6–7 سنوات تقريبًا، دافئة ومرِحة وحنونة.
- **اللغة:** فصحى مبسّطة واضحة (MSA)، ولا بأس بدفء خليجي خفيف، دون لهجة عامية.
- **السرعة:** غير سريعة؛ أبطأ قليلًا من الكلام العادي، وكل كلمة واضحة.
- **عبارات التشجيع** (أحسنتِ، فازت، رباعية، عيد ميلاد سعيد): حماس وفرح واضحين.
- **التعليمات** (المسي…، صِلي…): هادئة وواضحة.
- **الأسئلة** (كم…؟ أين…؟ أيهما…؟): نغمة سؤال فضولية لطيفة.
- **أسماء الحروف:** نطق واضح جدًا لمخارج الحروف (ص/س، ض/د، ط/ت، ظ/ذ، ح/هـ، ع/أ، ق/ك).
- **الأعداد:** واضحة ومنفصلة، بلا استعجال.
- **الأسماء والكلمات:** مرِحة، وكأنها تعرّف الطفل على صورة.
- **نهايات الكلمات:** نقف على آخر كلمة بالسكون (وقف طبيعي)، لذلك آخر حرف غالبًا بلا حركة إعراب. مثال: «كَمْ تُفّاحَة؟» تُنطق «تُفّاحَهْ».

### Voice Design (إن أردتِ تصميم الصوت)
اكتبي في خانة الوصف (بالإنجليزية):

```text
A cheerful, sweet young girl, about 6-7 years old, speaking clear Modern Standard Arabic with a slight warm Gulf touch. Warm, friendly, expressive, moderate pace, clean studio recording, no background noise.
```

إن لم تسمح المنصة بتصميم صوت طفلة، اختاري من مكتبة الأصوات صوتًا أنثويًا شابًا عالي النبرة ومرِحًا يجيد العربية.

## 2) الإعدادات المقترحة

**Eleven v3 (المفضّل لأنه يفهم وسوم الإحساس):**
- Stability: **Natural** (أو Creative إن كان الأداء جامدًا).
- انسخي كتلة «نص Eleven v3» للدفعة كما هي. الوسوم بين القوسين المربعين `[excited]` لا تُنطق، بل تحدد الإحساس.
- السطر `...` بين كل جملتين لإحداث وقفة نحو ثانية واحدة (مهم للتقطيع).

**Multilingual v2 (بديل):**
- Stability ≈ 50%، Similarity ≈ 75%، Style ≈ 25–35%، Speaker Boost: مفعّل، Speed ≈ 0.9.
- استخدمي كتلة «بديل Multilingual v2»: فيها `<break time="1.2s" />` بعد كل جملة، ولا توجد وسوم إحساس (الإحساس يأتي من إعدادات الصوت). إن لاحظتِ تشوّهًا بسبب كثرة الوقفات، قسّمي الدفعة إلى نصفين.

## 3) طريقة العمل

1. لكل دفعة: انسخي الكتلة ← ولّدي الصوت ← استمعي وتأكدي ← نزّلي الملف باسم `batch_01.mp3`، `batch_02.mp3` …
2. إن أخطأ الصوت في كلمة: أعيدي توليد الدفعة، أو ولّدي تلك الجملة وحدها وسمّيها باسم الـ `id` من الجدول (مثل `well_done_f.mp3`).
3. أرسلي ملفات الدفعات وسأقطّعها آليًا عند فترات الصمت وأسمّيها حسب جدول المرجع، ثم أتحقق أن عدد المقاطع يطابق الجدول.
4. **لا تغيّري ترتيب الأسطر** — الترتيب هو ما يربط كل مقطع باسمه.
5. الأرقام في جداول المرجع للتحقق فقط؛ كتل النسخ لا تحتوي أرقامًا.

## 4) ملاحظات على التشكيل والصيغ

- **المؤنث والمذكر:** اللعبة تختار حسب الثيم (بناتي/ولادي)، لذلك سُجّلت الصيغتان:
  `well_done_f` «أَحْسَنْتِ!» / `well_done_m` «أَحْسَنْتَ!» · `try_again_f` «حاوِلي» / `try_again_m` «حاوِلْ» ·
  `num_touch_f` «اِلْمِسي» / `num_touch_m` «اِلْمِسِ» · `num_search_f` «اِبْحَثي» / `num_search_m` «اِبْحَثْ» ·
  `num_match_f` «صِلي» / `num_match_m` «صِلْ» · `bf_touch_f/m` · `bf_touch3/4/5_f/m` · `bf_free_f` «لِتَعْرِفي» / `bf_free_m` «لِتَعْرِفَ».
- **فاز/فازت:** اللعبة كانت تقول «فاز» للجميع؛ صُحّحت: `won_f` «فازَتْ» لأثير وبشرى وريلا، و`won_m` «فازَ» لكوتي وسونى واللاعب الأول/الثاني، ثم يُشغَّل مقطع الاسم.
- **«كم» + تمييز منصوب:** «كَمْ كَتْكوتًا؟»، «كَمْ دَبْدوبًا؟»، «كَمْ بالونًا؟»، «كَمْ أَرْنَبًا؟»، «كَمْ ضِفْدَعًا؟» (الصحيح فصيحًا)، وكلمات التاء المربوطة بالوقف: «كَمْ تُفّاحَة؟».
- **الأعداد المركبة:** «ثَلاثَةَ عَشَرْ» — السكون على آخرها للوقف.
- **العدد مع المعدود:** «ثَلاثَ / أَرْبَعَ / خَمْسَ فَراشات» (المعدود مؤنث فالعدد مذكر).
- **الصفة مع المنصوب:** «اِلْمِسي الفَراشاتِ ذاتَ النِّقاط» (منصوبة)، و«هذِهِ فَراشَةٌ … ذاتُ نِقاط» (مرفوعة) — لذلك لهما مقطعان مختلفان.
- **همزة الوصل:** «اِلْمِسي»، «اِبْحَثي»، «اِثْنان» تبدأ بكسرة لأنها في أول الكلام.
- **«أَلِف»** مشكولة حتى لا تُقرأ «ألْف» (العدد).
- **الأسماء:** «بُشْرى» و«سونى» قد يقرؤهما الصوت بالياء؛ إن حدث ذلك اكتبيهما صوتيًا («بُشْرا»، «سونا» أو حسب النطق الصحيح للاسم) وأعيدي توليد السطر فقط.
- **كلمات أجنبية** (بيتْزا، ساكْسُفون، فْلامِنْغو، تيرانوصور، بودينغ…) شُكّلت بقدر الإمكان؛ استمعي إليها جيدًا.

## قواعد تركيب الجمل لكل لعبة

`g` = اللاحقة `_f` في ثيم البنات و`_m` في ثيم الأولاد (مثل `App.g`). المقاطع تُشغَّل متتابعة بلا فاصل تقريبًا (≈ 80–120 ms).

### عام (الفقاعات، الحلوى، الفروق، المتاهة، الانزلاق، الثعبان، الأشكال، المكعبات، الذاكرة، الفراشات، الأرقام)
- عند الفوز: `well_done_g`.

### الأرقام
| الحالة | التركيب | مثال |
|---|---|---|
| عدّ الأشياء | `num_count_<thing>` | «كَمْ تُفّاحَة؟» |
| أكثر / أقل | `num_which_more` / `num_which_less` | |
| الجمع | `num_<a>` + `num_plus` + `num_<b>` + `num_q_sum` | خمسة + زائد + ثلاثة + كم المجموع؟ |
| الطرح | `num_<n>` + `num_minus` + `num_<k>` + `num_q_left` | |
| ابحث عن الرقم | `num_touch_g` + `num_<t>` | المسي الرقم + سبعة |
| بعد خطأ في «ابحث» | `num_search_g` + `num_<t>` | |
| صِل كل رقم | `num_match_g` | |
| لمس شيء/رقم/مكعب أثناء العد | `num_<n>` (0–20) | |
| خطأ في مجموعة | `lets_count` | |
| إجابة خاطئة | `try_again_g` | |

`<thing>` من قائمة THINGS: apple, banana, strawberry, orange, chick, fish, ladybug, butterfly, turtle, bee, teddy, ball, balloon, car, star, flower, cookie, duck, rabbit, frog, cherry, cake.

### الفراشات
| الحالة | التركيب |
|---|---|
| مهمة لون | `bf_touch_g` + `col_<c>_def` |
| مهمة نقش | `bf_touch_g` + `bf_pat_<p>_def` |
| لون + نقش | `bf_touch_g` + `col_<c>_def` + `bf_pat_<p>_def` |
| مهمة عدد (3–5) | `bf_touch<n>_g` + `col_<c>_ind` |
| لمس فراشة خاطئة | `bf_this_is` + `col_<c>_ind` [+ `bf_pat_<p>_ind` إن لم تكن سادة] |
| الحديقة الحرة — البداية/زر السماعة | `bf_free_g` |
| الحديقة الحرة — لمس فراشة | `col_<c>` |

`<c>`: red, yellow, blue, green, pink, purple, orange, white, black, brown — `<p>`: dots, stripes.
مثال: «المسي الفراشات الزرقاء ذات النقاط» = `bf_touch_f` + `col_blue_def` + `bf_pat_dots_def`؛ «المسي ثلاث فراشات حمراء» = `bf_touch3_f` + `col_red_ind`.

- اختيار الشكل: round→`w_round`، square→`w_square_f`، heart→`w_heart`، star→`w_star`.
- اختيار النكهة: vanilla→`w_vanilla`، choco→`w_chocolate`، straw→`w_strawberry`، rainbow→`w_rainbow`.
- الطلبات: `cake_order_01` … `cake_order_15` (جملة كاملة لكل طلب حسب ترتيب ORDERS).

### للتنفيذ لاحقًا
أسهل ربط في الكود: جدول من النص المنطوق الحالي بعد حذف التشكيل والشدّة ← `id`، مع معالجة الجمل المركبة أعلاه (الأرقام، الفراشات، الحروف، الذاكرة) بتشغيل قائمة مقاطع بالتتابع، والرجوع إلى TTS إن لم يوجد مقطع.
