# البشرى تكنولوجي — Al-Bushra Technology

صفحة هبوط تجمع كل تطبيقاتنا وألعابنا، ومعها صفحة مطوّر محمية بكلمة مرور.

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة العامة: المنتجات (شعار، اسم، وصف، روابط: افتح / Google Play / APK)، تصفية وبحث، نموذج الاقتراحات وردود المطوّر |
| `admin.html` | صفحة المطوّر: كلمة المرور، إظهار/إخفاء/إضافة/تعديل/حذف/ترتيب التطبيقات، الردّ على الاقتراحات، نصوص الموقع، النسخ الاحتياطي |
| `data/catalog.json` | الكتالوج الافتراضي (كل المنتجات من المستودعات) |
| `config.js` | رابط الخادم `apiBase` |
| `worker/` | خادم Cloudflare Worker + KV (اختياري لكن مطلوب ليرى الجميع التعديلات والاقتراحات) |

## كلمة المرور
عند فتح `admin.html` أول مرة يطلب الموقع **إنشاء كلمة المرور** (6 أحرف على الأقل)، وبعدها تُطلب في كل دخول.
تُحفظ مشفّرة (PBKDF2-SHA256)، ويمكن تغييرها من «الإعدادات».

## وضعا التشغيل
- **محلي** (`apiBase` فارغ): الموقع يقرأ `data/catalog.json`. تعديلات المطوّر والاقتراحات تُحفظ في المتصفح نفسه فقط — يكفي للمعاينة. لنشر تعديلاتك: «الإعدادات ← تصدير JSON» ثم استبدل `data/catalog.json`.
- **خادم** (`apiBase` = رابط الـ Worker): كل تعديل واقتراح وردّ يظهر فورًا لكل الزوّار، وكلمة المرور على الخادم.

### نشر الخادم (مرة واحدة)
```bash
cd bushra-tech/worker
npx wrangler login
npx wrangler kv namespace create BUSHRA_KV     # انسخ الـ id إلى wrangler.toml
npx wrangler secret put SETUP_KEY               # اختياري: يمنع غيرك من تعيين كلمة المرور قبلك
npx wrangler deploy                             # يعطيك رابطًا مثل https://bushra-tech.<حسابك>.workers.dev
```
ضع الرابط في `config.js` ← `apiBase`، ثم افتح `admin.html` (أو `admin.html?key=SETUP_KEY` إن ضبطته) وأنشئ كلمة المرور فورًا.

## النشر
الموقع ملفات ثابتة فقط — يعمل على GitHub Pages أو Netlify أو Cloudflare Pages بنسخ مجلد `bushra-tech/` كما هو.

## إضافة روابط Google Play
من صفحة المطوّر ← تعديل التطبيق ← «رابط Google Play»؛ أو في `data/catalog.json` عبر الحقل `playUrl`.
