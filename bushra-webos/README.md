# البشرى لشاشات webOS

تطبيق خفيف (HTML و JavaScript بلا أطر عمل) لشاشات LG و webOS، يعمل حتى على webOS 4.

- **المصادر:** رابط M3U، أو حساب Xtream (روابط `get.php` تتحول لحساب تلقائيًا)، مع تحديث يومي.
- **الأقسام:** الرئيسية (تابع المشاهدة، المفضلة، الجديد)، مباشر (مجموعات + قنوات + الآن والقادم)، أفلام، مسلسلات بمواسمها، بحث، قوائمي.
- **المشغل:** HLS الأصلي في الشاشة (و hls.js احتياطًا)، الاستكمال من آخر موضع، الحلقة التالية تلقائيًا، ورابط بديل حين تتعطل القناة.
- **الريموت:** أسهم و OK ورجوع، CH± والأرقام للقنوات، ◀ قائمة القنوات، والأزرار الملونة: أحمر المفضلة، أخضر القنوات، أصفر مسار الصوت، أزرق مؤقت النوم. ومؤشر Magic Remote يعمل أيضًا.

## التثبيت
1. ثبّت تطبيق **Developer Mode** من متجر LG، وسجّل بحساب مطوّر LG مجاني، وفعّل «Dev Mode Status» ثم أعد تشغيل الشاشة.
2. على الحاسوب: `npm i -g @webos-tools/cli` ثم `ares-setup-device` (أدخل عنوان IP الشاشة)، ثم
   `ares-install AlBushra-webOS-1.0.0.ipk` و `ares-launch com.albushra.webos`.
   أو استخدم برنامج **webOS Dev Manager** بواجهة رسومية.

## البناء
`ares-package bushra-webos` — ويبنيه `.github/workflows/bushra-webos.yml` تلقائيًا وينشره في Releases.
