# البشرى — مشغّل الفيديو و IPTV

<p align="center"><img src="assets/logo.png" width="140" alt="شعار البشرى"></p>

> **شاهد ما تحب، بسهولة.** غرفة مشاهدة عربية تجمع البث المباشر والأفلام ودليل البرامج وفيديوهات جوالك في تطبيق واحد.

تطبيق **Flutter** واحد يعمل:
- 📱 **تطبيقًا على الجوال** (أندرويد، و iOS عند البناء على ماك) — مشغّل أصلي ExoPlayer (Media3).
- 📺 **على Android TV / Google TV** — يظهر في مشغّل التلفاز، ويدعم الريموت (OK، رجوع، القناة +/−، تشغيل/إيقاف).
- 🌐 **في المتصفح** — مشغّل ويب يعتمد HLS.js و mpegts.js مع كشف قدرات المتصفح.

## ✨ المزايا
| القسم | ما يقدّمه |
|---|---|
| **الرئيسية** | «تابع المشاهدة» بتبويبين: **أكمل المشاهدة** (ما بدأته ولم تنهه، مع «استكمال من 12:48 · متبقٍ 32 دقيقة») و**بدأت مشاهدته**؛ ثم بطل «يبث الآن» حين يوجد برنامج يستحق، ويبث الآن، والمفضلة، والأكثر مشاهدة، وأضيفت حديثًا، والمجموعات |
| **البث المباشر** | شريط حالة (القائمة، آخر تحديث، العدد، الاتصال، «تحديث القائمة»)، مجموعات أفقية بأيقونات، تصفية، تبويب أفلام ومسلسلات، لوحة معلومات جانبية على التلفاز |
| **دليل البرامج** | وضع زمني (شبكة + خط «الآن» + لوحة تفاصيل البرنامج + اليوم/غدًا) ووضع بطاقات للهاتف؛ XMLTV (و .gz) أو دليل حساب Xtream تلقائيًا |
| **قوائمي** | رابط M3U/M3U8، ملف من الجهاز، حساب Xtream Codes — مع **اختبار ومعاينة** قبل الحفظ؛ عند فشل التحديث تبقى آخر نسخة ناجحة بشارة «بيانات قديمة» |
| **ملفاتي** | تشغيل **فيديوهات الجوال** (MP4، MKV، MOV…) دون نسخها أو رفعها، مع حفظ موضع التوقف؛ وتشغيل رابط مباشر |
| **المتابعة** | صفحة كاملة: أكمل المشاهدة، بدأت مشاهدته، شاهدته بالكامل |
| **المشغل** | ملاءمة/ملء (بلا تمدد)، ±10 ث ونقر مزدوج، القناة التالية/السابقة، الجودة (تلقائي/يدوي)، مسارات الصوت، السرعة، قفل الشاشة، صورة داخل صورة، معلومات البث، الإبلاغ عن مشكلة، وحالات كاملة: جارٍ الاتصال، اتصال بطيء، انقطاع مع إعادة محاولة بعد 5 ثوانٍ، رابط منتهٍ، صيغة غير مدعومة، بث محمي |
| **البحث** | بحث واحد في القنوات والأسماء الأصلية والمجموعات والبرامج والقوائم والملفات — بلا تشكيل، ويسامح خطأ كتابة، مع مرادفات (رياضة/sport…) |
| **الإعدادات** | التشغيل، الصوت والترجمة، المظهر (**نمطان: هادئ وسينمائي**، داكن/فاتح/تلقائي، حجم النص، تقليل الحركة، تباين أعلى)، الرقابة الأبوية برمز يقفل مجموعات ويحمي المصادر |

### 🎨 نمطا التصميم
- **هادئ (الافتراضي):** أسطح ليلية متدرجة، فيروزي للإجراء وذهبي للتمييز فقط.
- **سينمائي (البديل):** شريط ضوئي فيروزي/ذهبي في الخلفية، بطاقات زجاجية بحافة مضيئة، أزرار ذهبية، وشريط جانبي بالشعار الكبير وعنصر نشط متوهج.

يُبدَّل من **الإعدادات ← المظهر ← نمط التصميم**.

## 🔒 الخصوصية والحقوق
- كل البيانات على الجهاز فقط؛ بيانات الدخول وروابط المصادر في **التخزين الآمن** ولا تظهر كاملة في الواجهة.
- البشرى أداة تشغيل وتنظيم ولا يوفّر أي محتوى، ولا يتجاوز أنظمة الحماية (DRM).

## 🛠️ البناء
```bash
cd bushra
flutter pub get
flutter run -d chrome                # الويب
flutter build apk --release          # أندرويد (موقّع بمفتاح android/bushra.keystore)
flutter build web --release --base-href /Games/bushra/app/
```
- يبني **GitHub Actions** (`.github/workflows/bushra.yml`) ملف APK ونسخة الويب تلقائيًا عند أي تعديل في `bushra/`، وينشرهما في **Releases**.
- **لا تغيّر** `android/bushra.keystore` وإلا لن تُثبَّت التحديثات فوق النسخة القديمة.
- رقم الإصدار في `pubspec.yaml` (`version: 1.0.0+1`): ارفعه مع كل إصدار.

### ملاحظات الويب
المتصفح يفرض قيودًا لا تخص التطبيق: مصادر **http** لا تعمل من صفحة **https**، وبعض المزودين يمنعون التشغيل من صفحات الويب (CORS). يشرح التطبيق ذلك للمستخدم، ويمكن ضبط وسيط من **الإعدادات ← الشبكة**؛ أما تطبيق الجوال والتلفاز فلا يحتاج ذلك.

## 🗂️ البنية
```
lib/
  core/      الألوان والخطوط والشعار (theme.dart, brand.dart)
  data/      النماذج، محلل M3U، عميل Xtream، XMLTV، البحث، المخزن (Hive + تخزين آمن)
  player/    واجهة المشغل الموحدة + ExoPlayer (الجوال) + HLS.js/mpegts.js (الويب) + شاشة المشغل
  screens/   الرئيسية، البث المباشر، الدليل، قوائمي، ملفاتي، المتابعة، البحث، الإعدادات، الترحيب
  widgets/   البطاقات وحلقة التركيز والخلفية السينمائية
web/vendor/  hls.js 1.6.15 و mpegts.js 1.8.0 (محلية، بلا CDN)
```
