# صور بطاقات «أنا منو؟»

ضع هنا صورة كل مهنة باسم الـ `slug` الموجود في `../cards.js` وبامتداد `png` أو `jpg` أو `webp`.
مثال: `doctor-m.png` · `engineer-f.jpg` · `chef-m.webp`

بعد إضافة الصور شغّل من جذر المستودع:

```bash
node scripts/build-sw.js
```

فيولّد `manifest.json` (قائمة الصور) ويحدّث `sw.js` لتُخزَّن الصور للعمل دون إنترنت.

البطاقة التي لا صورة لها تُعرض تلقائيًا برمزها ولونها ولافتة اسمها — واللعبة تعمل كاملة بدونها.
كما يمكن إضافة الصور من داخل اللعبة: **🖼️ صور البطاقات** (تُحفظ داخل الجهاز، ويطابقها التطبيق بأسماء الملفات).
