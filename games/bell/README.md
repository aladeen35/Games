# 🔔 تحدّي الجرس الثنائي — Ding Dong Dash

لعبة مسابقات عربية تنافسية للاعبَين على شاشة واحدة، بتصميم «دفتر مدرسي» مرسوم بالحبر الملوّن.

## التشغيل
افتح `index.html` مباشرة في أي متصفح حديث — لا يحتاج إنترنت ولا خادماً (الخطوط والشعار مضمّنة داخل الملف).
اللعبة تعمل في **الوضع الأفقي فقط**؛ عند فتحها عمودياً تظهر شاشة تطلب تدوير الجهاز.

## اللعب
- **4 مراحل × 10 أسئلة** تُختار عشوائياً من بنك يضم **105 أسئلة** دون تكرار داخل المرحلة:
  1. **رموز على الطاولة** — خمّن الخضار/الفاكهة من الإيموجي (30 سؤالاً)
  2. **الصورة تتّضح** — صورة ضبابية تنكشف كل ثانية وتتجمد عند الجرس (25)
  3. **خمس ثوانٍ** — معلومات عامة سريعة (30)
  4. **من الشعار؟** — رسوم تجريدية أصلية لعلامات مشهورة (20)
- أول جرس يقفل البقية، ثم عدّاد إجابة **5 ثوانٍ** بنبض متصاعد، والحكم يقرر: ✔ صحيحة / ✘ خاطئة.
- عند الخطأ أو انتهاء الوقت تنتقل **فرصة رد واحدة** للاعب الآخر.
- «وقت الحسم» في الأسئلة الثلاثة الأخيرة عند تقارب النتيجة، وشريط زخم بعد 3 إجابات متتالية.

## أدوات الحكم
- إيقاف مؤقت، إعادة السؤال، تخطي، إنهاء بتأكيد، سجل آخر 5 نتائج.
- زر 👁 لإظهار الإجابة للحكم (ضغط مطوّل).
- **وضع الجرس المكتبي**: أزرار «سجّل جرس اللاعب 1/2» مع اختصارات لوحة المفاتيح
  `A` = جرس اللاعب 1، `L` = جرس اللاعب 2، `مسافة` = كتم الصوت.
- إعدادات: خصم نقطة عند الخطأ، صافرة البداية، كثافة المؤثرات (هادئ/افتراضي/حماسي)،
  مستويات صوت مستقلة (جرس/عدّاد/احتفال)، زر تركيز يخفض الأصوات الثانوية إلى 25%، اهتزاز اختياري.

## تقنياً
ملف HTML واحد: CSS يدوي بأسلوب الدفتر + JavaScript خالص + أصوات مولّدة عبر Web Audio API.
يدعم `prefers-reduced-motion` وقارئات الشاشة (`aria-live` لكل الحالات الحاسمة).

بنية المصدر في `src/index.template.html` (قالب بلا أصول مضمّنة)، ويُبنى `index.html` بحقن الخطوط والشعار base64.
