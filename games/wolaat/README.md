# 🔥 ولعت — لعبة السودان الجماعية

لعبة لوحية سودانية تُلعب على الكمبيوتر أو الجوال **في الوضع الأفقي**، من **ثلاثة أشخاص أو أكثر**:
**حكم** واحد يفتح الغرفة ويدير الجولة، و**لاعبان على الأقل** (حتى ستة).

> ارمِ الزهرة ← تحرّك ← واجه الحدث ← اجمع النقاط ← استخدم **الهبابة** في الوقت المناسب ←
> وما تثق في تقدّمك حتى آخر جولة. صاحب أعلى رصيد يأخذ لقب **🏆 الولّاع**.

تطبيق ويب تقدّمي (PWA) بملف واحد قابل للتثبيت، **يعمل بدون إنترنت** في وضع الجهاز الواحد
ووضع النوافذ المتعددة — الخط والصور وكل المنطق مضمّنة محليًا.

---

## 🎖️ شاشتان مختلفتان

### لوحة تحكم الحكم
| ما يراه الحكم | التفاصيل |
|---|---|
| **الرقعة كاملة** | مواقع كل اللاعبين وأدوارهم لحظيًا |
| **كروت اللاعبين كلها** | كرت الهبابة الذي أخذه كل لاعب في البداية (المغلق عن الجميع) + الكروت المكتسبة خلال الجولة |
| **الإجابات النموذجية** | تظهر مع كل كرت «أسألني» — للحكم فقط |
| **تأكيد الإجابات والتحديات** | ✅ إجابة صحيحة (النقاط كاملة) · ❌ إجابة خاطئة (صفر) |
| **منح نقاط جزئية** | مثال: أجاب اللاعب إجابة ناقصة ← امنحه **٥ من ١٠** بعدّاد ± |
| **مؤقّت تحديات أركز** | ابدأ / أوقف / صفّر |
| **الموافقة على كروت الهبابة** | كل استخدام يمرّ عليه: اسمح · ارفض · أو دع الهدف يفتح **كرت الدرع** |
| **أدوات إدارة** | ±٥ سريعة، تعديل رصيد أي لاعب، منح كرت هبابة، نقل الدور، تخطّي دور، **رجوع خطوة**، **حفظ** |

### شاشة اللاعب
| ما يراه اللاعب | التفاصيل |
|---|---|
| **الرقعة** في مكانه | مع موقع قطعته وبقية اللاعبين |
| **نرده** | زر «رمي النرد» يعمل في دوره فقط |
| **الكرت المطروح** | كرته أو كرت اللاعب الآخر في هذه الجولة — بدون الإجابة النموذجية |
| **درجاتك ودرجة الخصم** | أعلى الشاشة، مع الهدف ولافتة الجولة الأخيرة |
| **كروتك الخاصة** | المكتسب **مفتوح** للجميع · وكرت البداية **مغلق دائمًا** — يطّلع عليه صاحبه بزر 👁️ ويستخدمه في أي جولة أو في آخر اللعبة |
| **الونسة** | عبارات سودانية سريعة + كتابة حرّة |

## 🎮 طرق اللعب الثلاث

| الوضع | كيف يشتغل | إنترنت؟ |
|---|---|---|
| 📱 **جهاز واحد** | الجهاز مع الحكم، وفي دور كل لاعب يفتح له شاشته الخاصة («مرّر الجهاز») | ❌ |
| 🖥️ **نوافذ متعددة** | كل لاعب يفتح اللعبة في نافذة جديدة على نفس الجهاز ويدخل برمز الغرفة | ❌ |
| 🌐 **أجهزة مختلفة** | كل واحد بجواله على نفس الرابط ويدخل برمز الغرفة (WebRTC) | ✅ |

الحكم دائمًا هو **المرجع**: كل الحسابات تجري على جهازه، واللاعبون يستقبلون حالة منقّاة
لا تكشف الإجابات النموذجية ولا كروت غيرهم المغلقة ولا ترتيب الكروت القادمة.

## 🗺️ الرقعة والخانات

٤٠ خانة حول محيط الرقعة، البداية أعلى اليمين والحركة باتجاه القراءة العربية.
الأركان: **البداية** · **الركشة** · **النهاية** · **الراكوبة**.

| | الخانة | ما يحدث |
|---|---|---|
| 🔵 | **أسألني** (٩ خانات) | سؤال سوداني بـ٥ / ١٠ / ١٥ نقطة — الحكم يقيّم |
| 🟠 | **أركز** (٨) | تحدي بمؤقّت: تمثيل، سرعة، ذاكرة، ارتجال |
| 🟢 | **يا سلكت يا فككت** (٧) | حظ يرفعك أو يوقعك، يُنفَّذ فورًا |
| 🔴 | **كرت هبابة** (٣) | تكسب كرتًا استراتيجيًا تحتفظ به (٣ كروت كحد أقصى) |
| 💰 | **جكة** (٣) | +٥ أو +١٠ فورًا |
| 💥 | **فككت** (٢) | −٥ أو −١٠ فورًا |
| 🌴 | **ريح ضهرك** (٢) | تفقد دورك القادم |
| 🚪 | **النفاج** (٢) | انتقال إلى أي خانة، أو تبديل مكان مع لاعب |
| 🛺 | **الركشة** | تقدّم ٥ خانات |
| 🛖 | **الراكوبة** | حماية من الهبابة + رمية إضافية |
| 🏁 | **النهاية** | +١٠ وكرت هبابة · واللفّة الكاملة حول الرقعة +٥ |

### الجولة الأخيرة
الوصول إلى الهدف (**٥٠** سريع أو **٨٠** طويل) لا يعني الفوز: تبدأ **جولة أخيرة**
يقدر فيها الجميع يولّعوا كروت الهبابة، وكرت **الفرملة** يضيف جولة كاملة إضافية.
بعد انتهائها تُحتسب النتائج ويُعلَن الولّاع.

## 🗂️ إضافة الكروت

### الطريقة الأولى — ملف `cards.js` (تنطبق على كل الأجهزة)
كل الكروت في ملف واحد، وكل مجموعة مصفوفة مستقلة. أضِف كروتك في نهاية المصفوفة المناسبة:

```js
asalni: [
  { q: 'سؤالك هنا؟', a: 'الإجابة النموذجية', pts: 10, cat: 'تاريخ' },
],
arkiz: [
  { text: 'نص التحدي', pts: 10, sec: 20 },
],
salakt: [
  { kind: 'salakt', text: 'سلكت! تقدّم خانتين.', fx: { move: 2 } },
  { kind: 'fakakt', text: 'فككت! ارجع خانتين.', fx: { move: -2 } },
],
hababa: [
  { title: 'اسم الكرت', text: 'شرح الكرت', fx: { pts: 10 }, timing: 'anytime' },
],
```

مفاتيح التأثير `fx` كلها موثّقة في أعلى `cards.js`:
`pts` · `move` · `moveTo` · `moveToNearest` · `extraRoll` · `skip` · `shield` · `giveHababa` ·
`double` · `extraRound` · `forceChallenge` · `counter` · `quiz` · `steal` · `swapScore` ·
`swapPos` · `targetPts` · `targetMove` · `targetSkip` · `blockHababa`.

و`timing` لكروت الهبابة: `anytime` (حتى في دور لاعب آخر) أو `own` (في دوره فقط).

### الطريقة الثانية — من داخل اللعبة (على هذا الجهاز فورًا)
الشاشة الرئيسية ← **🗂️ الكروت** ← الصق JSON بنفس الشكل أعلاه (أو ارفع ملفًا) ← **أضف الكروت**.
تُحفظ على الجهاز وتُخلط مع كروت `cards.js` بدون تعديل أي كود.

**المجموعة الحالية: ١٠٢ كرت** — أسألني ٤٠ · أركز ٢٢ · يا سلكت يا فككت ٢٤ · هبابة ١٦.

## 🚀 التشغيل والنشر

```bash
# محليًا
python3 -m http.server 8000
# ثم افتح http://localhost:8000/wolaat/
```

**النشر (دقيقتان):** اسحب مجلد `wolaat` وأفلته في **app.netlify.com/drop** → تحصل على رابط `https`.
افتح الرابط من الجوال ← قائمة ⋮ ← **إضافة إلى الشاشة الرئيسية** → يعمل كتطبيق مستقل وبدون إنترنت.

**ملف APK:** ضع رابط `https` في **pwabuilder.com** ← Android ← Generate Package.

> ⚠️ وضع **«أجهزة مختلفة»** يحتاج `https` (أو `localhost`) لأن WebRTC لا يعمل على `http` عادي.
> الوضعان الآخران يعملان في كل الحالات.

## 📦 محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة والأنماط (شاشة الحكم، شاشة اللاعب، الغرفة، القواعد، الكروت) |
| `cards.js` | **بيانات الكروت — عدّل هذا الملف لإضافة كروت جديدة** |
| `game.js` | محرّك اللعبة: الرقعة، الأدوار، التأثيرات، النقاط، الجولة الأخيرة |
| `net.js` | طبقة الاتصال: جهاز واحد / نوافذ متعددة / أجهزة مختلفة |
| `app.js` | الربط والرسم والأصوات والمؤثرات |
| `manifest.json` · `sw.js` | التثبيت والعمل دون اتصال |
| `assets/` | الشعار وظهور الكروت الأربعة (WebP مضغوط) |
| `fonts/` · `vendor/` | خط Baloo Bhaijaan 2 محليًا · مكتبة الاتصال WebRTC |

الحجم الكامل أقل من **٧٥٠ كيلوبايت**. لا إعلانات، لا تتبّع، ولا بيانات تخرج من الجهاز —
حالة اللعبة تُحفظ في `localStorage` على جهاز الحكم فقط.
