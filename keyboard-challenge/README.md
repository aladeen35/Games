# ⌨️ تحدي الـ Keyboard مع أبو جنان

<p align="center"><img src="public/assets/logo.webp" width="180" alt="شعار تحدي الـ Keyboard مع أبو جنان"></p>

لعبة سباق كتابة عربية بطابع سوداني: تختار الكاتوجري ونوع النص، وتكتب أسرع من منافسيك — **منفردًا** ضد منافسين آليين، أو **أونلاين** مع أصحابك، أو **بالبلوتوث** بين جهازين بدون إنترنت.

## 📱 تطبيق أندرويد (APK)

الملف الجاهز: **[`release/AbuJinanKeyboard-2.0.apk`](release/AbuJinanKeyboard-2.0.apk)** — يعمل على أندرويد 5.0 فأحدث.

- **منفرد وبلوتوث**: يعملان مباشرة بدون إنترنت.
- **أونلاين**: من ⚙️ الإعدادات اكتب عنوان الخادم (مثل `https://my-server.example` أو `http://192.168.1.10:8080` على نفس الشبكة).
- **البلوتوث**: جهاز يضغط «افتح غرفة» والتاني «انضم لغرفة» ويختار الجهاز. الأسرع أن تقرن الجهازين من إعدادات البلوتوث أولًا.

البناء: `bash android/build-apk.sh` (أو `KB_SERVER_URL=https://… bash android/build-apk.sh` لتضمين عنوان خادم افتراضي).
يحتاج `aapt2 javac zipalign apksigner` و `android.jar` (منصة 23)، ومُجمّع DEX الموجود في `../android/tools/`.

> مفتاح التوقيع يُنشأ في `android/keystore/` (غير مرفوع). احتفظ به لتثبيت التحديثات فوق النسخة القديمة.

## 🎮 طريقة اللعب

1. **الانترو** ← **الرئيسية**: العب منفرد، أونلاين، بلوتوث، ترتيب الأسبوع، طريقة اللعب.
2. **اختار الكاتوجري**: ألغاز وحكم ومقولات سودانية · معلومات عامة · جمل تشجيعية · جمل إسلامية وأحاديث · الجودة للجميع · أو 🎲 عشوائي.
3. **نوع الكتابة**: جمل بسيطة · جمل طويلة (3 إلى 5 سطور) · مقالات وقصص قصيرة.
4. **سرعة المنافسين**: هادي · معتدل · صاروخ — وتحدد أيضًا سخاء الوقت، والوقت يُحسب حسب طول النص.
5. عد تنازلي 3-2-1 ثم **اكتب كلمة كلمة**: الخانة تفضى بعد كل كلمة صحيحة، والأخضر صح والأحمر غلط والذهبي الحرف الجاي.

**في الهاتف** يختفي كيبورد اللعبة ويُستخدم كيبورد الهاتف، والشاشة تنقسم تلقائيًا حسب حجمه: المضمار فوق، ثم النص، ثم خانة الكتابة.

## 📚 النصوص (450 نصًا)

كل كاتوجري فيها **30 جملة بسيطة + 30 جملة طويلة + 30 مقالًا أو قصة** في `shared/texts/`، وتظهر بترتيب عشوائي كامل (كيس خلط يمر على كل النصوص قبل أي تكرار).

- **الأحاديث** كاملة بلا اقتصاص، بدون الرواة والإسناد، مع ذكر المصدر تحت النص (لا يُكتب). لا توجد آيات قرآنية في النصوص تجنبًا لأي خطأ في النقل.
- **الجودة للجميع**: معلومات سلامة الغذاء وفق مفاتيح منظمة الصحة العالمية الخمسة والممارسات المعتمدة.
- كل النصوص بلا تشكيل ولا رموز صعبة، ويتحقق منها: `node scripts/validate-texts.js`.

## 🏃 وضعيات أبو جنان

5 وضعيات × 3 حركات: `run` يجري · `error` يجري مع خطأ · `near` قرب الفوز · `won` فاز · `lost` خسر.
ضع الصور في `public/assets/poses/` (مثل `run-1.webp` … `lost-3.webp`) وسجّل أسماءها في `poses.json` — تُستخدم تلقائيًا في المضمار والمدرب والنتيجة. إلى أن تتوفر تظهر الصورة الأساسية بحركة CSS لكل وضعية.

## 🖥️ الخادم (للّعب الأونلاين)

يحتاج **Node.js 22.5+** فقط، بلا اعتماديات (SQLite مدمجة):

```bash
pnpm start          # http://localhost:8080
pnpm check          # الصياغة + المعرّفات + تباين الألوان + الاختبارات
pnpm build          # ينتج dist/ ثم: pnpm start:dist
```

| متغير البيئة | الافتراضي | الوظيفة |
|---|---|---|
| `PORT` | `8080` | منفذ الخادم |
| `DB_PATH` | `data/keyboard.db` | ملف قاعدة البيانات |
| `STATIC_DIR` | — | خدمة الواجهة من مجلد مبني (مثل `dist`) |

- الغرف: إنشاء بكود من 5 خانات أو رابط دعوة، بدء موحّد بعد عد تنازلي، تزامن كل 2.5 ثانية، **جولة جديدة بنص جديد** في نفس الغرفة، ونقل الملكية إذا غاب المنشئ.
- الحماية: الخادم يحسب WPM بنفسه ويرفض الأزمنة غير المنطقية، وحد 8 نتائج في الدقيقة.
- التطبيق يتصل بالخادم برمز `Bearer`، والخادم يسمح بـ CORS بلا كوكيز.

إجراءات `POST /api/<الاسم>`: `auth.register` · `auth.login` · `auth.logout` · `auth.me` · `presence.ping` · `room.create` · `room.join` · `room.state` · `room.start` · `room.rematch` · `room.progress` · `room.finish` · `room.leave` · `round.start` · `round.finish` · `leaderboard.weekly`
