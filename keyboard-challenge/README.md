# ⌨️ تحدي الـ Keyboard مع أبو جنان

<p align="center"><img src="public/assets/logo.webp" width="180" alt="شعار تحدي الـ Keyboard مع أبو جنان"></p>

لعبة سباق كتابة عربية بطابع سوداني تعمل من المتصفح على الكمبيوتر والهاتف. اكتب الجملة بأسرع وقت وأعلى دقة، وخلي أبو جنان يجري من **اليمين إلى اليسار** حتى خط النهاية.

## التشغيل

يحتاج **Node.js 22.5+** فقط — بلا أي اعتماديات خارجية (قاعدة البيانات هي SQLite المدمجة `node:sqlite`).

```bash
cd keyboard-challenge
pnpm start          # http://localhost:8080
pnpm check          # فحص الصياغة + المعرّفات + تباين الألوان + الاختبارات
pnpm build          # ينتج dist/ ثم: pnpm start:dist
```

| متغير البيئة | الافتراضي | الوظيفة |
|---|---|---|
| `PORT` | `8080` | منفذ الخادم |
| `DB_PATH` | `data/keyboard.db` | ملف قاعدة البيانات |
| `STATIC_DIR` | — | خدمة الواجهة من مجلد مبني (مثل `dist`) |

> بدون خادم (استضافة ثابتة لمجلد `dist/`) يعمل **اللعب الفردي** كاملًا، وتظهر رسالة أن الغرف ولوحة الترتيب غير متاحة.

## ما تم تنفيذه

- **اللعب الفردي**: ثلاثة مستويات (هادي 55 ث، معتدل 42 ث، صاروخ 42 ث) بجمل سودانية مختلفة، وثلاثة منافسين آليين بسرعات حسب الوثيقة (65–78%، 78–94%، 92–108%).
- **الكتابة**: الأخضر صحيح، الأحمر خطأ، والذهبي هو الحرف الحالي. الأخطاء **تراكمية** — تصحيحها بالمسح لا يعيد الدقة. تُقبل `,` و`?` و`;` اللاتينية بدل العربية. اللصق ممنوع.
- **الحساب**: `WPM = (الحروف / 5) / الدقائق`، والدقة = الصحيح / المكتوب × 100، والتقدم = الحروف الصحيحة / طول الجملة.
- **كيبورد عربي مرئي** (تخطيط Arabic 101) يُبرز المفتاح التالي، ويُبرز Shift أو ⌫ عند الحاجة.
- **الغرف**: إنشاء بكود من 5 خانات، انضمام بالكود أو **برابط دعوة** `?room=CODE`، بدء من المنشئ فقط، تزامن كل 2.5 ثانية، حالة «غير نشط»، إعادة إرسال النتيجة تلقائيًا بعد انقطاع الخادم، و**نقل ملكية الغرفة** إذا غاب منشئها قبل البدء.
- **ترتيب الأسبوع**: من الإثنين 00:00 UTC، أفضل نتيجة لكل لاعب (WPM ← الدقة ← الأقدم)، مع فلتر المستوى.
- **الحماية من النتائج الوهمية**: الخادم يحسب WPM بنفسه من زمن الإكمال، ويرفض أي زمن أقصر من الممكن (بحد 220 WPM) أو أطول من زمن الخادم منذ بدء الجولة، والجولة الفردية لا تُسجَّل إلا مرة واحدة، وحد أقصى 8 نتائج في الدقيقة لكل لاعب.
- **الصوت** عبر Web Audio (بدء، ضغط صحيح، خطأ، إكمال، دخول غرفة، فوز، انتهاء الوقت) مع زر كتم يُحفظ، ولا يبدأ الصوت قبل أول تفاعل.
- **الوصولية**: احترام `prefers-reduced-motion`، تباين ≥ 4.5:1 يُفحص آليًا، وبديل نصي عند فشل تحميل الشعار أو الشخصية.

## إجراءات الخادم

كل الإجراءات `POST /api/<الاسم>` بجسم JSON:

`auth.register` · `auth.login` · `auth.logout` · `auth.me` · `presence.ping` · `room.create` · `room.join` · `room.state` · `room.start` · `room.progress` · `room.finish` · `room.leave` · `round.start` · `round.finish` · `leaderboard.weekly`

## بنية المشروع

| المسار | الوظيفة |
|---|---|
| `shared/game.js` | منطق اللعبة المشترك (الجمل، الحساب، المتتبع، الأسبوع) |
| `server/` | الخادم وقاعدة البيانات والحسابات والإجراءات |
| `public/` | الواجهة: `index.html` و`app.js` و`styles.css` و`audio.js` و`keyboard.js` |
| `test/` | اختبارات المنطق وتكامل الواجهة البرمجية (`node:test`) |
| `scripts/` | `check.js` و`build.js` |
