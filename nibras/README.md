# نِبراس | NIBRAS — نتعلّم باللعب.. ونكتشف المستقبل

<p align="center"><img src="icon-512.png" width="140" alt="نبراس"></p>

**نسخة MVP تجريبية (0.2)** من منصة ألعاب تعليمية من الروضة إلى المرحلة المتوسطة، مبنية حسب «وثيقة الرؤية والتطوير».
تعمل **دون إنترنت تمامًا** (APK أو PWA)، بلا إعلانات، وكل البيانات على الجهاز فقط.

📱 الملف الجاهز: [`dist/Nibras-0.2.apk`](dist/Nibras-0.2.apk) — أندرويد 5.0 فأحدث.

## ما يقدّمه هذا الإصدار
| الوثيقة | التنفيذ |
|---|---|
| بلا حسابات | 3 شاشات ترحيب (مع اختيار اللغة) ثم الدخول مباشرة؛ الصف يُغيَّر من الرئيسية بلمسة، ولا أسماء ولا بيانات شخصية |
| 5 عوالم تعليمية | حديقة الاكتشاف · قرية الحروف والأعداد · مدينة المعرفة · مملكة العلوم والمهارات · مختبر العقول |
| مسارات المواد ← وحدات ← دروس | خريطة مسار لكل مادة وصف، والدروس السابقة مفتوحة دائمًا للمراجعة |
| 4 ألعاب أساسية | البحث عن الكلمات (عربي RTL/إنجليزي، سحب أو لمستان، صور ونطق ومعنى) · المطابقة · الترتيب (حروف/كلمات/أعداد/خطوات) · الاختيار (اسمع واختر، صواب وخطأ، اكتشف الخطأ) |
| تسلسل النشاط | هدف الدرس + مثال ← لعب ← تلميح ← شرح عند تكرار الخطأ ← سؤال تطبيقي ← تقرير «ما تعلّمته» |
| النجوم الثلاث | ⭐ الفهم · ⭐ الاستقلالية (قلة التلميحات) · ⭐ التطبيق |
| الإتقان | 6 حالات (لم تبدأ، قيد التعلّم، تحتاج دعمًا، قريبة، متقنة، تحتاج مراجعة) — لا إتقان من محاولة واحدة |
| المراجعة المتباعدة | بعد يوم ← 3 أيام ← أسبوع ← أسبوعين ← شهر، مع بنك للأسئلة الخاطئة و«مراجعة ذكية» و«تحدّي اليوم» |
| المكافآت | نقاط خبرة، 7 شارات، متجر شخصيات بنقاط اللعب فقط (لا مشتريات حقيقية) |
| المؤقت | بلا مؤقت افتراضيًا؛ «تحدّي وقت» اختياري لا يؤثر في النجوم ولا يظهر للروضة والصفين 1–2 |
| ولي الأمر | بوابة حسابية، تقرير المهارات، المهارات التي تحتاج دعمًا، حد يومي للاستخدام، تغيير الصف، حذف البيانات |
| الوصول | 3 أحجام خط، تباين مرتفع، تقليل الحركة، قراءة صوتية (عربي/إنجليزي)، لمس بدل السحب، علامات ✓✗ لا الألوان وحدها |

## المحتوى
28 درسًا نموذجيًا (135 نشاطًا) في الروضة والصفوف 1، 2، 3، 4، 6، والأول والثالث المتوسط (عربي، رياضيات، علوم، إنجليزي، جغرافيا، أشكال وألوان) بأمثلة من البيئة السودانية.
⚠️ **كل المحتوى توضيحي** (`status: prototype_only`) ويجب مطابقته مع الكتب الرسمية (الكتاب، الإصدار، الوحدة، الصفحة) ومراجعته قبل اعتماده. التطبيق غير معتمد رسميًا من الوزارة. التربية الإسلامية مؤجلة حتى مراجعة النصوص من مختصين.

## البنية (فصل المحرّك عن المحتوى)
```
js/content.js   بيانات المنهج والدروس (سجلات بحقول لوحة الإدارة المستقبلية)
js/games.js     محرّك الألعاب — كل نوع نشاط يُسجَّل في N.Games ويُضاف دون تعديل الباقي
js/core.js      التخزين، الملفات، الإتقان والمراجعة، الشارات، الصوت والنطق، حد الوقت
js/visuals.js   الشعار المتجهي والمرئيات (عدّ، مجموعات، كسور، جداول، خريطة...)
js/app.js       الشاشات وتسلسل الدرس والنتائج ونوافذ ولي الأمر
brand/          ملفات الهوية البصرية المعتمدة
```
لإضافة درس: أضف سجلًا إلى `lessons` في `content.js`. لإضافة نوع لعبة: `N.Games.newType = { mount(act, api) {...} }`.

## البناء
```bash
bash nibras/android/build-apk.sh
```
ارفع `VERSION_CODE`/`VERSION_NAME` في السكربت مع كل إصدار، ولا تغيّر `nibras.keystore`.

## خارج نطاق هذا الإصدار
الخادم والمزامنة، لوحة إدارة المحتوى ودورة الاعتماد، حسابات المعلّم والفصول، تنزيل حزم المحتوى. سجل المحاولات يُحفظ بمعرّفات فريدة تمهيدًا للمزامنة دون تكرار.
