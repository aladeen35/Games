# نسخة Google Play — ألعاب أبو جنان

كل ما يلزم لرفع التطبيق إلى متجر Google Play، جاهز في هذا المجلد.

```
playstore/
├─ README.md               ← هذا الدليل
├─ listing-ar.txt          ← نصوص المتجر بالعربية (اسم، وصف مختصر، وصف كامل، ملاحظات الإصدار)
├─ listing-en.txt          ← نفسها بالإنجليزية (لغة افتراضية مطلوبة)
├─ console-answers.md      ← إجابات نماذج «أمان البيانات» و«تصنيف المحتوى» وبقية الأسئلة
├─ frame.html              ← قالب لقطات المتجر (يُعاد توليده عند تغيّر التصميم)
├─ feature.html            ← قالب الصورة المميزة
├─ raw/                    ← لقطات خام من اللعبة (خارج git — تُولَّد بـ shots.mjs)
└─ out/
   ├─ app-icon-512.png     ← أيقونة التطبيق 512×512
   ├─ feature-graphic.png  ← الصورة المميزة 1024×500
   ├─ phone/               ← 10 لقطات JPEG بمقاس 1080×1920
   ├─ tablet7/             ← 10 لقطات JPEG بمقاس 1200×1920
   └─ tablet10/            ← 10 لقطات JPEG بمقاس 1440×2304
```

## ما ينقص: ملف AAB

متجر Google Play يقبل **حزمة Android App Bundle (.aab)** فقط للتطبيقات الجديدة.
بناؤها يحتاج Android SDK والوصول إلى `dl.google.com`. عند توفّرهما:

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk bash scripts/build-playstore.sh
```

ينتج المجلد `playstore/release/` ويضمّ ملف AAB وملف APK وكل ملفات المتجر في مكان واحد،
بعد فحص آلي يتأكد أن المحزوم هو آخر نسخة من اللعبة وليس نسخة قديمة.

## خطوات الرفع في Play Console

1. **إنشاء حساب مطوّر** على <https://play.google.com/console> (رسم تسجيل 25 دولاراً يُدفع مرة واحدة).
2. **Create app**: الاسم «ألعاب أبو جنان»، اللغة الافتراضية «العربية»، النوع **Game**، مجاني.
3. **Store listing** → انسخ النصوص من `listing-ar.txt`، وارفع الأيقونة والصورة المميزة واللقطات من `out/`.
4. **Store settings** → الفئة: ألعاب ← **Board**، وبريد التواصل، ورابط الموقع.
5. **Privacy policy** → `https://aladeen35.github.io/Games/abujanan/privacy.html`
6. **App content** → املأ النماذج من `console-answers.md`:
   أمان البيانات · تصنيف المحتوى · الإعلانات (لا) · الوصول للتطبيق · الجمهور والمحتوى.
7. **Production → Create new release** → ارفع ملف `.aab`، وانسخ ملاحظات الإصدار.
8. **Countries** → اختر كل البلدان (أو ابدأ بالدول العربية).
9. **Send for review** — المراجعة تستغرق عادةً من بضع ساعات إلى أيام.

## ملاحظات مهمة

- **Play App Signing**: اقبله عند أول رفع. يصبح مفتاحك مفتاح رفع فقط، ويحتفظ Google بمفتاح
  التوقيع النهائي — فلو ضاع مفتاحك لا تفقد التطبيق.
- **مفتاح التوقيع مكشوف حالياً**: `android/abujanan-release.keystore` وكلمة مروره داخل مستودع
  GitHub عام. اجعل المستودع خاصاً أو انقل المفتاح خارجه قبل الرفع.
- **إذن الموقع**: أندرويد ١١ فأقدم يشترط `ACCESS_FINE_LOCATION` للبحث عن أجهزة البلوتوث.
  Play سيسأل عن سبب الإذن — الإجابة جاهزة في `console-answers.md`.
- **`targetSdk`**: Play يشترط هدفاً حديثاً للتطبيقات الجديدة. المشروع يبني حالياً على 36، وهو كافٍ.

## إعادة توليد صور المتجر

اللقطات مبنية من اللعبة نفسها، فإن تغيّر التصميم أعد توليدها:

```bash
npx http-server -p 8412 -s .      # في جذر المشروع
node playstore/render.mjs          # لقطات الهاتف واللوحي
node playstore/feat.mjs            # الصورة المميزة
```
