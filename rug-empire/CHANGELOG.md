# سجل التغييرات

## 1.0.0 — 2026-11-12
إعادة بناء كاملة فوق فكرة النسخة 0.1.0 المرجعية.

- **محاكاة أعمق:** كيمياء بدرجة حموضة وزمن مكوث وحرارة ماء، ست مواد تنظيف ومنع الخلط الخطر، نزف ألوان ينتشر فعلياً ويمكن إنقاذه، تثبيت البقع بالماء الحار، إجهاد الألياف، صعود الأوساخ العميقة عند التجفيف، اتجاه الوبر.
- **عرض جديد:** وبر طبقي (Shell Texturing) يميل مع اتجاه التمشيط ويتلبّد بالبلل، رغوة تتسخ بالماء المتسخ، خرائط الأوساخ والرطوبة وبقايا المنظف، ثلاث بيئات (حوش، ورشة، صالة عرض).
- **تحذيرات حية** تشرح الخطأ وهو ما زال قابلاً للإصلاح، ونصائح «عم الطيب».
- **تايم لابس:** تسجيل كل الحركات وإعادتها مسرّعة من كاميرا علوية عمودية مع شعار المحل وتصدير فيديو.
- **ثلاث لغات:** فصحى وسودانية وإنجليزية، بفصل لغة الواجهة عن لغة الحوار وترجمة سفلية اختيارية.
- **صالة العرض:** حفظ كل سجادة بثلاث نجوم فأكثر، منصة دوّارة، شريط قبل/بعد، الجناح الذهبي، البيع.
- **الأعمال:** مساومة، أربعة مسارات سمعة، سبع رتب، مهارات، أربعة مقارّ، عمال، الصندوق، تأمين، سوق السجاد المستعمل، التقويم الهجري وزحمة ما قبل العيد.
- **الجودة:** 30 اختبار Vitest، محاكي توازن، فحص ترجمة، اختبار شامل بـ Playwright، بناء APK موقّع وسير عمل GitHub Actions.
