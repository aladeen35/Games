# إمبراطورية السجاد — Rug Empire

لعبة محاكاة ثلاثية الأبعاد لغسيل السجاد وإدارة مغسلة في نسخة خيالية مستوحاة من الخرطوم. تعمل في المتصفح (جوال وحاسوب) وتُغلَّف كتطبيق أندرويد من المصدر نفسه. المواصفات في `docs/` (خمسة ملفات)، وحالة كل نظام في `TASKS.md`.

## اللعب

- **الويب:** مجلد `www/` ملفات ثابتة جاهزة. يكفي رفعه إلى أي استضافة HTTPS فيصير PWA قابلاً للتثبيت ويعمل بلا إنترنت.
- **أندرويد:** ملف `dist/RugEmpire-<الإصدار>.apk`. مع كل دفع إلى GitHub يبني سير العمل `Rug Empire APK` ملفاً جديداً، وتجده في صفحة التشغيل تحت **Artifacts** (يُحمَّل من متصفح الجوال).

## التطوير

```bash
npm install
npm run dev          # خادم محلي على http://localhost:5173 مع إعادة بناء تلقائية
npm test             # اختبارات Vitest: المحاكاة، الاقتصاد، الحفظ، الترجمة
npm run i18n:check   # مفاتيح ترجمة ناقصة
npm run balance      # محاكي التوازن: لاعبون آليون لمئات الأيام بلا رسوميات
npm run build        # يولّد www/game.js (ملف واحد يعمل داخل WebView)
bash android/build-apk.sh   # APK موقّع (التفاصيل في android/README.md)
node tools/smoke.mjs        # اختبار شامل في متصفح حقيقي مع لقطات شاشة (والخادم يعمل)
```

`py serve.py` بديل بلا Node يخدم `www/` كما هو.

## البنية

| المسار | المحتوى |
|---|---|
| `src/content.js` | كل البيانات وقيم التوازن: الخامات، البقع، الكيمياء، الأدوات، الاقتصاد، الزبائن، الفصول |
| `src/sim.js` | محاكاة الغسيل والتجفيف والتقييم. منطق صرف بلا عرض، وحتمي (أساس التايم لابس) |
| `src/state.js` | المحفظة والدفتر المركزي، التقويم الميلادي والهجري، الطقس، الطلبات، التقدم، الحفظ |
| `src/scene.js` | مشهد Three.js: شيدر السجادة بالوبر الطبقي، الأدوات، الجسيمات، الإضاءة، البيئات الثلاث |
| `src/session.js` | جلسة الغسيل: الأدوات والتحذيرات الحية، التجفيف، النتيجة، الدفع، التايم لابس |
| `src/app.js` | القوائم، مركز الأعمال، صالة العرض، الإعدادات |
| `src/strings.js`, `src/i18n.js` | النصوص بثلاث لغات وسلسلة الرجوع `ar-SD → ar → en` |
| `src/patterns.js` | نقوش السجاد والأوراق النقدية الخيالية والشعار، مرسومة بالكود |
| `src/audio.js` | صوت إجرائي وموسيقى طبقية بـ WebAudio |
| `tests/`, `tools/` | الاختبارات، البناء، محاكي التوازن، فحص الترجمة، الاختبار الشامل |
| `android/` | غلاف WebView وسكربت بناء الـAPK ومفتاح التوقيع |

## قرارات تقنية

- **Three.js بجافاسكربت صرف** كما في النسخة المرجعية، لا Godot: المطلوب ويب + أندرويد من مصدر واحد يُبنى من GitHub Actions دون حاسوب.
- **حزمة واحدة بصيغة IIFE** (esbuild) لأن وحدات ES لا تُحمَّل بسهولة داخل WebView.
- **المحاكاة بخطوة ثابتة (30 مرة في الثانية)** ومدخلات مسجَّلة، فإعادة التشغيل تعطي النتيجة نفسها تماماً.
- **المبالغ أعداد صحيحة** وكل حركة تمر عبر `tx()` في `state.js`.
- الأسعار قيم لعب خيالية وليست أسعار سوق. الأوراق النقدية مجسّمات لعبة مكتوب عليها «عملة لعبة».

## ملاحظة عن النسخة المرجعية
