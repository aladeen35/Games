# الجزء الأول: اللعبة بثلاث لغات

## 1. اللغات المدعومة

| الرمز | اللغة | الاتجاه | الاستخدام |
|---|---|---|---|
| `ar-SD` | **اللهجة السودانية** | RTL | روح اللعبة: الحوار والزبائن والتجار والعمال |
| `ar` | **العربية الفصحى** | RTL | لكل العرب، وللقوائم الرسمية والفواتير |
| `en` | **English** | LTR | للاعبين من العالم |

## 2. اختياران منفصلان: لغة الواجهة ولغة الحوار

يختار اللاعب في الإعدادات (وأول مرة يشغّل فيها اللعبة):

| الإعداد | الخيارات | المثال |
|---|---|---|
| **لغة الواجهة** (القوائم، الأزرار، الدفاتر) | الفصحى / السودانية / English | |
| **لغة الحوار** (كلام الشخصيات) | السودانية / الفصحى / English | |

**تركيبات شائعة:**
- واجهة فصحى + حوار سوداني: **الإعداد الافتراضي**. القوائم واضحة لكل عربي، والشخصيات تتكلم بروح الخرطوم.
- كل شيء سوداني: لأهل البلد ولمن يحب الأجواء الكاملة.
- واجهة إنجليزية + حوار سوداني مع **ترجمة سفلية إنجليزية**: تجربة ثقافية للاعب الأجنبي.
- كل شيء بالإنجليزية.

> **ترجمة سفلية اختيارية:** عند اختيار الحوار السوداني يمكن تفعيل سطر صغير تحته بالفصحى أو الإنجليزية، فيفهمه أي لاعب ويتعلم اللهجة في الوقت نفسه.

## 5. مراعاة القواعد والسياق

- **التذكير والتأنيث:** مخاطبة الزبون تتغير حسب جنسه، وكلام الشخصيات عن اللاعب يتغير حسب جنس شخصيته. يُستخدم سياق i18next:
  `customer.thanks_male` / `customer.thanks_female`.
- **الجمع العربي:** المفرد والمثنى والجمع (سجادة، سجادتان، 3 سجادات، 11 سجادة) عبر قواعد الجمع في i18next.
- **الأرقام:** اختيار بين الأرقام العربية (123) والهندية (١٢٣) للعربيتين، والفاصل بالآلاف في الأسعار: `25,000 ج.س` أو `SDG 25,000`.
- **العملة في الإنجليزية:** `SDG` مع اسم "Sudanese Pound" في الشرح.
- **الاحترام:** اللهجة تُكتب بمحبة وواقعية، لا للسخرية. كل نصوص السودانية تُراجَع من متحدث أصلي قبل الإطلاق.

## 6. التنفيذ التقني

```
src/locales/
├─ ar-SD/  ui.json  dialogue.json  tutorial.json  items.json  events.json  showroom.json
├─ ar/     (نفس الملفات)
├─ en/     (نفس الملفات)
└─ glossary.json
```

- **سلسلة الرجوع:** `ar-SD → ar → en`. إذا نقصت جملة سودانية تظهر بالفصحى بدل أن تظهر فارغة.
- **قلب الاتجاه لحظياً:** `document.dir` يتغير مع اللغة، والتخطيط يستخدم خصائص CSS المنطقية (`margin-inline-start` بدل `margin-left`) فتنعكس الواجهة تلقائياً.
- **الخطوط:** Cairo أو Tajawal للعربية، وInter أو Poppins للإنجليزية. `troika-three-text` يأخذ الخط والاتجاه من اللغة الحالية للافتات داخل المشهد.
- **الحوار الصوتي (اختياري لاحقاً):** ملفات صوت منفصلة لكل لغة حوار، مع بقاء النص المكتوب دائماً.
- **أدوات فحص:**
  - سكربت `npm run i18n:check` يكشف المفاتيح الناقصة أو الزائدة بين اللغات الثلاث.
  - **ترجمة وهمية للاختبار** (نصوص أطول بـ 40%) لكشف الأزرار التي يُقص نصها.
  - لقطات Playwright لكل شاشة باللغات الثلاث للمقارنة البصرية.

# الجزء الثاني: «صالة لَمْعة» — المتجر قبل دخول اللعبة

## 7. الفكرة

من **القائمة الرئيسية** وقبل الدخول إلى عالم اللعبة، يدخل اللاعب إلى صالة عرض ثلاثية الأبعاد فاخرة. فيها تُعرض **كل السجادات التي أكملها** (غسيلاً أو ترميماً)، ويستطيع تأملها ومقارنتها قبل وبعد، ومشاهدة التايم لابس الخاص بها، وبيعها، وشراء مقتنيات وتجميلات.

### مسار الشاشات
```
شاشة البداية ← اختيار اللغة (أول مرة فقط) ← القائمة الرئيسية
                                              ├─ ابدأ / واصل ← اختيار ملف الحفظ ← عالم اللعبة
                                              ├─ صالة لَمْعة ← (الأقسام الأربعة)
                                              ├─ الإعدادات (اللغة، الرسوميات، الصوت)
                                              └─ الإنجازات
```

## 8. أقسام الصالة الأربعة

### القسم الأول: «معرض أعمالي»
- كل سجادة أكملها اللاعب بتقييم **3 نجوم فأعلى** تُحفظ تلقائياً كقطعة معروضة.
- تُعلَّق على الجدران أو تُفرش على منصات أو تُكدَّس كما في محلات السجاد الحقيقية.
- **عند اختيار سجادة:**
  - تنتقل الكاميرا إليها بسلاسة وتُعرض على **منصة دوّارة** تحت إضاءة مركّزة.
  - **شريط سحب "قبل/بعد"** يكشف السجادة المتسخة كما استلمها والنظيفة كما سلّمها.
  - **زر التايم لابس** لمشاهدة الغسيل كاملاً مسرّعاً بمقاس 9:16 وتصديره.
  - **بطاقة السجادة:** النوع والخامة والمقاس، النجوم وتفصيل الدرجات، الوقت والماء المستهلك، اسم الزبون وقصته، التاريخ الميلادي والهجري ويوم اللعب والفصل.
- **التحف الخاصة:** السجادات التي حصلت على 5 نجوم أو رُمّمت ترميماً كاملاً تُعرض في **جناح ذهبي** بإطار وإضاءة مميزة.

### القسم الثاني: «سوق الصالة»
- السجادات التي **اشتراها اللاعب متسخة ثم غسلها أو رممها** (لا سجاد الزبائن) يمكن عرضها للبيع هنا.
- يحدد اللاعب السعر، ويزور الصالة **مشترون افتراضيون** بأذواق وميزانيات مختلفة، فيبيع بعضهم ويساوم آخرون (بحوار المساومة نفسه باللغة المختارة).
- **السعر المقترح** يُحسب من: نوع السجادة، جودتها، درجة نظافتها، الترميم، والموسم (قبل العيد أغلى).
- البيع يُضاف **بالأوراق النقدية** إلى ملف الحفظ المرتبط، وتظهر حركة عدّ الأوراق المعتادة.
- سجادة مبيعة تبقى في "معرض أعمالي" بعلامة **«بِيعت»** للذكرى.

### القسم الثالث: «الخزانة» (التجميلات)
تُشترى بعملة اللعبة أو بـ **نجوم الإنجاز**:
- ملابس للشخصية: أزياء عمل بألوان مختلفة، جلابية، عمة، شال، توب للشخصيات النسائية.
- ألوان وزخارف للأدوات: ماكينة بلون مخصص، مسّاحة بمقبض خشبي.
- إطارات للشعار واللافتة، وأنماط إضاءة للمحل.
- خلفيات وموسيقى للتايم لابس.
- **قاعدة:** التجميلات للشكل فقط، ولا تعطي أي أفضلية في التقييم أو الاقتصاد.

### القسم الرابع: «معرض المجتمع» (عند الاتصال بالإنترنت)
- أجمل سجادات اللاعبين الآخرين، والفائزون بتحدي السجادة اليومية.
- إعجاب بالأعمال، ونسخ **نقش سجادة** صممها لاعب آخر إلى محرر النقوش.
- زيارة صالة صديق ومشاهدة تايم لابس أعماله.

## 9. تصميم الصالة ثلاثية الأبعاد

| العنصر | التفاصيل |
|---|---|
| المبنى | قاعة عالية السقف بأعمدة وأقواس مستوحاة من العمارة السودانية، وأرضية خشب أو رخام مصقول |
| العرض | جدران تعليق، رفوف سجاد ملفوف، منصات فرش، منصة دوّارة مركزية |
| الإضاءة | إضاءة دافئة عامة، وكشافات مركّزة على كل سجادة، ونافذة كبيرة يدخل منها ضوء الوقت الحالي في الخرطوم |
| الأجواء | الصالة نهاراً أو ليلاً حسب الساعة الحقيقية للاعب، وصوت موسيقى خفيفة، وصوت أذان من بعيد في وقته |
| التنقل | حاسوب: نقر وسحب وعجلة الفأرة. جوال: سحب بالإصبع بين السجادات، وقرص للتكبير |
| السعة | تبدأ الصالة بعدد محدود من أماكن العرض، وتتوسع بأجنحة جديدة مع التقدم |
| التحميل السريع | تُعرض صور مصغّرة أولاً، ثم تُحمّل الخامة الكاملة للسجادة عند الاقتراب منها |

## 10. نموذج بيانات السجادة المكتملة

```ts
interface CompletedRug {
  id: string;
  saveSlotId: string;          // ملف الحفظ الذي أُكملت فيه
  seed: number;                // بذرة النقش، تكفي لإعادة توليده
  pattern: 'abstract' | 'medallion' | 'kilim' | 'prayer' | 'shag' | 'kids' | 'bursh' | 'custom';
  material: 'wool' | 'silk-synthetic' | 'polyester' | 'shag';
  sizeCm: { w: number; h: number };
  ownership: 'customer' | 'owned';   // سجاد زبون (عرض فقط) أو ملك اللاعب (قابل للبيع)
  beforeThumb: Blob;           // webp 256px
  afterThumb: Blob;
  afterFull: Blob;             // webp 1024px
  timelapseRef?: string;       // مرجع بيانات إعادة التشغيل
  score: { total: number; stars: 1|2|3|4|5; clean: number; safety: number; time: number; resources: number; site: number };
  stats: { minutes: number; waterL: number; restored: boolean };
  customer?: { nameKey: string; storyKey: string };  // مفاتيح ترجمة، لا نص ثابت
  completedAt: { gameDay: number; season: string; gregorian: string; hijri: string };
  status: 'gallery' | 'for-sale' | 'sold';
  price?: number;              // بالجنيه السوداني
}
```

- **قصص الزبائن تُخزّن كمفاتيح ترجمة**، فتظهر باللغة الحالية للاعب مهما تغيّرت.
- **التخزين:** IndexedDB عبر Dexie، مع ضغط الصور بصيغة WebP.
- **النطاق:** «معرض أعمالي» على مستوى **الحساب** (يجمع أعمال كل ملفات الحفظ)، أما **البيع** فمربوط بملف الحفظ الذي يملك السجادة حتى لا يُستخدم مال ملف في ملف آخر.

## 12. خطة التنفيذ

| المرحلة | المحتوى | معيار القبول |
|---|---|---|
| **أ** | بنية i18next بالثلاث، سلسلة الرجوع، قلب الاتجاه، الخطوط، سكربت الفحص | تبديل اللغة من الإعدادات يغيّر كل الشاشات فوراً دون إعادة تشغيل |
| **ب** | ترجمة كل النصوص الحالية + المسرد + التذكير والتأنيث والجمع | `i18n:check` يمر دون مفاتيح ناقصة |
| **ج** | الترجمة السفلية للحوار | جملة سودانية تظهر تحتها الفصحى أو الإنجليزية حسب الإعداد |
| **د** | القائمة الرئيسية + صالة العرض 3D + «معرض أعمالي» + قبل/بعد | كل سجادة مكتملة بـ 3 نجوم تظهر تلقائياً في الصالة |
| **هـ** | «سوق الصالة» والمشترون والمساومة | بيع سجادة يضيف المبلغ لملف الحفظ الصحيح فقط |
| **و** | «الخزانة» والتجميلات | التجميلات لا تغيّر أي قيمة في التقييم أو الاقتصاد |
| **ز** | «معرض المجتمع» (بعد الحفظ السحابي) | عرض أعمال لاعبين آخرين دون إبطاء الصالة |
